## 第 1 条：销售复盘不是问“为什么没成交”，而是拆这 6 个环节

链接：https://www.douyin.com/video/7660857104592358719

置顶，2.0 万赞。

### 核心观点

销售复盘不是追责，而是定位成交链路里的堵点。

### 知识点

- 复盘六环节：客户来源、需求确认、价值表达、信任建立、异议处理、跟进节奏。
- 客户来源：先判断客户值不值得跟。客户没有真实需求、预算不匹配、不是关键角色、只是问价或拿方案比价，说明问题在前端获客和客户筛选，不在逼单。
- 需求确认：至少要问清五件事：客户现在遇到什么问题、问题发生在哪个场景、带来什么影响、为什么现在想解决、选择方案时最看重什么。
- 价值表达：客户不是为产品功能付钱，而是为自己的问题被解决付钱。普通销售讲“我们有什么”，专业销售讲“客户用了以后能解决什么”。
- 信任建立：信任不靠“您放心、我们很专业”，靠同行案例、客户反馈、交付流程、服务标准、数据对比等证据。
- 异议处理：客户说贵、考虑、对比时，先拆出真实原因，不要马上降价或继续说服。
- 跟进节奏：每次沟通都要拿到下一步承诺，包括具体时间、谁参与、看什么资料、确认什么问题、推进到哪一步。

### 复盘常见五坑

- 把复盘开成批评会。
- 只听销售描述，不看客户行为证据。
- 只复盘失败单，不复盘成功单。
- 只问原因，不改成可执行动作。
- 复盘没有沉淀成团队标准。

## 第 2 条：销售一定要会提问：5 个问题，把单子一步步问成

链接：https://www.douyin.com/video/7654221255423380736

置顶，3.3 万赞。

### 核心观点

成交不是靠销售说服客户，而是让客户自己说服自己。

### 知识点

- 提问五步顺序：需求 → 痛点 → 预算 → 顾虑 → 引导决策。
- 问需求：不要直接问“你需要什么”，而是问“你现在是怎么做的 / 希望达到什么效果 / 现在用的有什么不满意”。
- 问痛点：需求是客户想要的，痛点是客户难以忍受的。可以问“这个问题困扰你多久了 / 如果不解决会有什么影响 / 最坏的结果是什么”。
- 问预算：不直接问“你有多少预算”，而是问“之前在这类事情上投入过多少 / 理想中愿意投入多少 / 想先试试还是一步到位”。
- 问顾虑：用开放式问题把客户担忧摆上台面，例如“还有哪些地方不太放心 / 做决定时还有哪些犹豫”，然后逐个解决。
- 引导决策：问“这个方案是不是正好能解决你的问题 / 我们可以先从哪一步开始 / 还有哪些是我没考虑周全的”，让客户顺着思路做决定。
- 提问原则：多用开放式问题、层层递进、带着真诚，避免像审问。

## 第 3 条：销售一定要会利他话术：6 个场景，把客户从逼走变想买

链接：https://www.douyin.com/video/7656841474457308466

置顶，5.2 万赞。

### 核心观点

只有真正为客户着想，客户才会愿意信任你并买单。

### 知识点

- 客户说太贵：不降价、不硬杠，把注意力转到“产品适不适合 + 能不能解决客户问题”，先谈价值再谈价格。
- 客户直接问多少钱：没有塑造价值前不要报价。先了解客户想解决什么问题，再推荐合适型号。
- 客户说再看看别家：不要阻止对比，给出 2-3 条关键挑选标准，并说“比完拿不准随时回来问我，买不买都没关系”。
- 客户买完说谢谢：不要只说“不客气”，要表达后续会主动跟进，再自然请求转介绍。
- 客户问最低价：不亮底牌，先了解用途，推荐最适合、性价比最高的方案。
- 客户说再考虑考虑：不要只说“好的”，要顺承并问出具体顾虑：“是不是还有哪里不确定？我可以帮你分析明白，买不买都没关系。”
- 四条底层心法：不跟客户对抗、价值塑造前不报价、不逼迫客户、把决定权还给客户。
