第一站 · LM Studio 下载两个模型
1

打开 LM Studio

点击：程序坞上的 LM Studio 图标（彩色立方体）。找不到就去「启动台」。
2

下载嵌入模型（理解笔记用，约 0.3GB，很快）

① 顶部 🔍 Search → ② 搜 nomic-embed-text → ③ 找 "nomic-embed-text-v1.5-GGUF"（nomic-ai 发布）→ ④ 进入详情 → ⑤ 选 Q4_K_M 版本 → ⑥ ⬇ Download
3

下载对话模型（回答问题用，约 4.7GB，等 10-20 分钟）

① 🔍 Search → ② 搜 Qwen2.5 → ③ 找 "Qwen2.5-7B-Instruct-GGUF"（Qwen 发布）→ ④ 进入详情 → ⑤ 选 Q4_K_M → ⑥ ⬇ Download
网慢的话换 Qwen2.5-3B-Instruct-GGUF（约 2GB），一样用。
4

确认下载完毕

顶部 📦 My Models → 看到两个模型就 OK
这一步完成 → 进入下一站
第二站 · LM Studio 开服务 + 开 CORS
5

加载对话模型

顶部 💬 Chat → 顶部模型下拉框 → 选 Qwen2.5-7B-Instruct → 等绿色 ✅ 出现
6

开启本地服务器

顶部 ⚙️ Developer → Local Server 区域 → 开关拨成 🟢 Running

看到地址 http://127.0.0.1:1234，这就是你电脑上的 AI 服务地址。

7

开启 CORS（⚠️ 最关键一步，漏掉后面全失败）

同一页 Local Server 区域 → 找 "Enable CORS" → 点成 ✅ 开启
反复确认：CORS 必须是 ✅ 开启状态。
8

加载嵌入模型

Developer 页 → Loaded Models → ➕ Load another → 选 nomic-embed-text-v1.5
这一步完成 → 进入最后一站
第三站 · Obsidian 配置 Smart Connections
你的 Obsidian 里已经装好了 Smart Connections 插件，不需要额外安装任何东西。 这是你搭建知识库的最后一站，只需要 3 步。
9

打开 Smart Connections 设置

Obsidian 左下角 ⚙️ 设置 → 左侧列表找到 「Smart Connections」（在「第三方插件」分组下）
10

照抄填写配置表

打开 Smart Connections 设置后，你会看到一个表单，请按照下面表格一项一项填：

看到这个设置项填这个值
Model Platform / API ProviderOpenAI Compatible 或 Custom
Base URLhttp://127.0.0.1:1234/v1
API Keylm-studio
Chat Model / Model Nameqwen2.5-7b-instruct
Embedding Modelnomic-embed-text-v1.5
填完找 「Test」或 「Verify」按钮 → 点一下 → 看到绿色 ✅ 就对了。红色 ❌ 的话检查 CORS 开了没有、地址有没有漏掉末尾的 /v1。
11

索引你的笔记库

在 Smart Connections 设置里找 「Sync vault」/「Index」/「Initialize」按钮 → 点它 → 等进度条走完

这一步把笔记转成 AI 能读懂的格式。100 篇笔记大约 1-2 分钟。

12

开始使用

索引完成后，Obsidian 右侧边栏会出现一个聊天面板。在聊天框里输入问题，AI 就会从你的笔记里找答案。

试试输入：「总结我最近三天写了什么」

🎉 全部完成！你的离线 AI 知识库可以用了。
