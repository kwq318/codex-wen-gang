# 🧠 Codex + LM Studio + Obsidian 闭环协作

## 一句话理解

> **Obsidian 是仓库，LM Studio 是本地搜索引擎，Codex 是你的 AI 管家。三者围着笔记转。**

## 三者分工

| 角色 | 能力 | 不能做的 |
|------|------|---------|
| **Codex（我）** | 读你的笔记、写你的笔记、分析内容、帮你整理、执行自动化 | 不可用时间外联系不到 |
| **LM Studio（本地）** | 离线搜索笔记、离线 AI 问答、数据不出电脑 | 不能帮你操作 Obsidian 外部的事情 |
| **Obsidian** | 存笔记、做索引、展示知识图谱 | 本身没有 AI 能力 |

## 闭环流程

```
你写笔记
    ↓
Obsidian 保存，Local LLM Helper 每 30 分钟自动索引
    ↓
你想搜东西 → Obsidian 里 Cmd+P → Chat → LM Studio 从笔记里找答案（离线）
    ↓
你想让 Codex 帮忙整理 → 告诉我 → 我读笔记 → 改写/总结/生成新笔记 → 写回 Obsidian
    ↓
新笔记又被 Local LLM Helper 自动索引 → LM Studio 也能搜到
    ↓
循环闭合 ✅
```

## 三个实际场景

### 场景一：日常搜索（离线）

**什么时候用：** 想找笔记里的东西，不想联网

**操作：**
1. Obsidian → Cmd+P → 输入 `LLM Chat` → 回车
2. 聊天框输入：「我上周写了关于车联网的什么内容？」
3. LM Studio 从笔记里找答案，带引用链接

### 场景二：批量整理（Codex 帮你）

**什么时候用：** 笔记多了乱，想让 Codex 帮忙归类、总结

**操作：**
1. 对 Codex 说：「帮我把 Desktop/桌面文稿/codex文稿 里关于销售的笔记，汇总成一份销售策略大纲，存为新笔记」
2. Codex 读取所有相关笔记 → 分析 → 生成新笔记 → 写入 Obsidian
3. 下次 LM Studio 自动索引，新笔记也能搜到

### 场景三：AI 辅助写作（两者配合）

**什么时候用：** 要写一篇新笔记，需要既有本地知识又有外部信息

**操作：**
1. 先让 Codex 帮你：「我有一篇关于无人配送车的笔记，帮我扩展市场分析部分」
2. Codex 读取旧笔记 → 补充内容 → 写回或创建新笔记
3. 然后 Obsidian 里用 LM Studio 离线验证：「总结这篇笔记的核心观点」

## 当前配置状态

| 配置项 | 值 | 作用 |
|--------|-----|------|
| 自动索引 | 每 30 分钟 | 笔记变更后自动让 LM Studio 能搜到 |
| RAG TopK | 10 | 每次问答返回最相关的 10 条笔记 |
| Max Tokens | 2048 | LM Studio 回答的最大长度 |
| Stream | 开启 | 回答逐字显示，不用等 |
