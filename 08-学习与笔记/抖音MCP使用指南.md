# 抖音 MCP 使用指南

## 这套技能能做什么

- 查抖音账号资料和最近作品
- 查账号置顶内容
- 下载抖音视频音频
- 用 Whisper 把口播转成文字稿
- 把完整知识点整理成 Obsidian 笔记

## 下次使用，直接发这些话

### 1. 只查账号内容

> 查这个抖音账号：`https://www.douyin.com/user/抖音号或数字ID`
> 获取账号资料和最近 10 条内容，整理到知识库

### 2. 查置顶内容并要完整知识点

> 查这个抖音账号：`https://www.douyin.com/user/抖音号或数字ID`
> 的置顶 3 条内容，每一条的知识点我都要

### 3. 要完整口播文字稿

> 下载这些抖音视频的音频，用 Whisper 转写，保留完整文字稿
> 然后把每条视频的知识点总结到 Obsidian

### 4. 指定保存位置

> 把结果写成笔记，放入 `08-学习与笔记/抖音账号/`
> 文件名用有意义的中文名称

## 我这边会执行什么

1. 用 `douyin` MCP 定位真实账号
2. 获取账号资料、作品列表、置顶内容
3. 必要时打开浏览器态 Chrome 绕过抖音验证
4. 用 yt-dlp 下载视频音频
5. 用 Whisper 转写完整口播
6. 根据口播提炼知识点
7. 写入 Obsidian 对应分类目录并打开

## 已安装信息

| 项目 | 位置 |
|------|------|
| 抖音 MCP | `douyin`，已注册到 Codex |
| MCP 代码 | `~/.codex/mcp-servers/Douyin_Spider/` |
| Cookie 配置 | `~/.codex/mcp-servers/Douyin_Spider/.env` |
| 浏览器登录态 | `~/.codex/mcp-servers/Douyin_Spider/.chrome-profile/` |
| 视频下载 | yt-dlp + Chrome Cookie |
| 语音转写 | Whisper + ffmpeg |

## 注意事项

- 桌面出现的 Chrome 窗口是抖音 MCP 的浏览器通道，尽量保持打开。
- 如果出现抖音验证码，手动完成一次后即可继续。
- 如果账号用纯数字链接查不到，我会先用用户搜索把数字 ID 转成真实账号 ID。
- 如果转写文字有少量同音错字，属于正常情况，我会整理成知识点时尽量修正。
- 如果 Cookie 过期，重新扫码登录即可，不需要重新安装 MCP。
