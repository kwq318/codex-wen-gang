§ Ⅰ

## 重要新闻动态

01已落地 / 部分未验证

### SoundHound 推进车内 Voice Commerce

SoundHound 8 月 5 日披露 Q2 收入 6,190 万美元，同比增长 45%；车载相关亮点包括中国汽车信息娱乐软件公司 7 位数合同、Stellantis 和 Hyundai 扩大 live generative AI 采用，以及新签汽车品牌推出车内 Voice Commerce。 <sup><a href="#ref-1">1</a></sup> 对我们而言，它正在把车内语音包装为“交易入口 + agent orchestration”。

02已落地 / 未验证

### Cerence 获 Stellantis 多品牌 xUI 奖项

Cerence 8 月 6 日披露 Q3 收入 6,960 万美元，同比增长 12%；Connected Services 收入增长超过 20%，并称获得 Stellantis 多品牌 Cerence xUI award 与 Mobile Work Agent 首个客户。 <sup><a href="#ref-2">2</a></sup> 这说明 OEM 仍重视车规集成、连接服务、权限边界和多品牌复用。

03已开放 API

### Grok Voice latest 切到 Think Fast 2.0

xAI Release Notes 显示 \`grok-voice-latest\` 自 8 月 5 日起路由到 \`grok-voice-think-fast-2.0\`；Voice Overview 标注 S2S、tool use、sub-second 和 3 美元 / 小时价格。 <sup><a href="#ref-3">3</a></sup> <sup><a href="#ref-4">4</a></sup> 车载 S2S 成本必须按音频时长、并发和常驻策略重算。

04已落地 / Beta

### Tesla Grok 仍与传统语音共存

Tesla 手册显示 Grok 可通过 “Hey Grok” 等方式启动，但需要 Premium Connectivity 或 Wi-Fi；当前仍为 early Beta，且传统车辆语音命令保持不变。 <sup><a href="#ref-5">5</a></sup> 量产路径更像“LLM Agent + 确定性车控兜底”，不是直接替换。

§ ⅡUX

## Agentic 语音体验趋势

### 任务执行与跨应用编排

SoundHound 的订餐、预约、停车支付、售后服务与 Cerence xUI / Mobile Work Agent 都指向同一方向：车内语音的核心指标应从识别率升级为任务完成率、跨应用步数减少和失败可恢复率。 <sup><a href="#ref-1">1</a></sup> <sup><a href="#ref-2">2</a></sup> <sup><a href="#ref-9">9</a></sup>

### 延迟与首响应

xAI 标注 S2S API 为 sub-second。车内应拆分“听见我了”的即时反馈和“可执行结果”的完成时间，让模型先给低风险确认，再异步完成工具调用。 <sup><a href="#ref-4">4</a></sup>

### 自然打断与对话流

r/ChatGPT 反馈显示，用户不一致偏好“更像真人”的停顿和语气；车内默认应采用短句、可打断、少情绪表演、强确认的任务语音。 <sup><a href="#ref-6">6</a></sup>

### 上下文记忆与多用户个性化

Tesla 社区对自动导航、Preferred Routes 和 Grok 命令扩展的关注，说明用户期待车辆根据日常路线、媒体偏好和车内角色减少重复输入；中文社区也认为 Tesla 语音仍弱于国内新势力。 <sup><a href="#ref-7">7</a></sup> <sup><a href="#ref-8">8</a></sup>

### 断网降级与本地兜底

Tesla 手册明确 Grok 依赖 Premium Connectivity 或 Wi-Fi，同时传统车辆语音命令保持不变。安全与高频车控应保留本地 ASR / 小模型 / 规则 DSL。 <sup><a href="#ref-5">5</a></sup>

§ ⅢModels

## 大模型厂商 S2S 规划

### API 已开放，但车端仍应分域接管

\`grok-voice-think-fast-2.0\` 与 \`grok-voice-latest\` 支持实时 S2S 和 tool use，文档标注 sub-second、3 美元 / 小时；Tesla 车端仍为 Beta，手册限定当前只支持导航相关命令。 <sup><a href="#ref-3">3</a></sup> <sup><a href="#ref-4">4</a></sup> <sup><a href="#ref-5">5</a></sup> 对我们而言，Grok 可作为北美项目对照，但出海 OEM 仍要封装模型路由层，避免单一生态锁定。

§ ⅣCompetition

## 车载语音玩家动向

### 从传统车载语音转向横向 Voice Agent 平台

Q2 披露显示 OASYS、Voice Commerce 和汽车客户扩展同时推进；其餐饮、电视、医疗、金融能力可迁移到车内，可能在出海 OEM 的生态服务接入环节形成先发优势。 <sup><a href="#ref-1">1</a></sup>

### 车规规模、连接服务和安全架构仍是护城河

Cerence Q3 的 Stellantis xUI、Mobile Work Agent 与 Connected Services 增长说明，它继续押注 OEM 多品牌复用和车内工作流；其安全文章强调 Zero Trust 与数据治理。 <sup><a href="#ref-2">2</a></sup> <sup><a href="#ref-9">9</a></sup>

## OEM 实装案例

### 已上车但处于 Beta 与分批灰度

Tesla 手册显示 Grok 已进入车端，支持 “Hey Grok” 与方向盘长按，但需要网络连接且传统语音命令保持不变；r/teslamotors 讨论显示用户期待打电话、播歌、调空调等功能，但也有灰度不可用反馈。 <sup><a href="#ref-5">5</a></sup> <sup><a href="#ref-7">7</a></sup>

§ ⅦImplications

## 对产品的启发

### 默认任务语音，不默认陪伴人格

驾驶模式优先短、准、可打断；乘客模式允许解释和多媒体；陪伴模式再开放情绪表达。可执行能力必须做成可见状态，避免灰度限制被用户理解为智能失败。 <sup><a href="#ref-5">5</a></sup> <sup><a href="#ref-6">6</a></sup> <sup><a href="#ref-7">7</a></sup>

### S2S 选型要看成本口径和编排层

xAI 按小时计费，SoundHound / Cerence 更偏平台和 OEM 集成；我们需要统一抽象层，让不同 S2S 模型可替换，同时自建任务编排与权限控制。 <sup><a href="#ref-1">1</a></sup> <sup><a href="#ref-2">2</a></sup> <sup><a href="#ref-4">4</a></sup>

### 车控接口必须分级授权

建议 OEM 将车控分为只读、低风险执行、高风险执行、安全关键四级，并为每级设置确认、审计和本地兜底。 <sup><a href="#ref-5">5</a></sup> <sup><a href="#ref-9">9</a></sup>

### Voice Commerce 与企业工作流进入车内

SoundHound 证明交易闭环开始签约，Cerence 证明 Mobile Work Agent 开始拿客户；机会在停车、充电、保养、订餐、日程与会议，但必须控制隐私和分心风险。 <sup><a href="#ref-1">1</a></sup> <sup><a href="#ref-2">2</a></sup>

§ ⅧActions

## 可以做的尝试

UX

### 三模式语音人格实验

做“驾驶 / 乘客 / 陪伴”三档系统提示和语速策略。

指标：首响应、打断成功率、用户主动切换率、驾驶中平均话轮长度。

Architecture

### 车控 DSL + S2S Agent 沙盒

让 S2S 模型只输出受限 DSL，不直连 CAN / 车控 API。

指标：高风险命令拦截率、误执行率、fallback 成功率。

Transparency

### 能力可用性面板

显示当前地区、车型、网络、账号下可用的语音能力。

指标：失败后重复尝试率、客服问题量、用户理解度。

Commerce

### Voice Commerce 小闭环

先选停车缴费、充电站筛选、保养预约、沿途咖啡下单四个低风险闭环。

指标：语音完成率、撤销率、修改成功率。

Cost

### S2S 成本压测

按每车每日 5 / 15 / 30 分钟音频会话和 10 万车峰值并发测算。

指标：单车月成本、峰值并发成本、本地兜底节省比例。
