摘要：中国汽车出海把"海外车载导航"从可选配置推成刚需入口。本文盘点 10 家主要服务商——国际阵营 HERE、TomTom、Google、Mapbox、NNG，中国出海阵营高德、百度、华为花瓣、东软、泰为——并从定位形态、地图覆盖、数据鲜度、车道级与 ADAS/ISA、座舱集成、本地化、实时动态、AI、合规、商业模式十个维度做同口径对比。

核心结论：国际图商赢在数据资产与合规纵深，中国阵营赢在工程化速度与体验一致性，双方正通过战略合作（HERE×百度、HERE×高德、TomTom×华为/腾讯）走向融合；选型应按目标市场法规门槛、生态路线与自研程度分层决策。

## 一、市场背景：海外车载导航为何成为刚需

中汽协数据显示，2025 年中国汽车出口 709.8 万辆、同比增长 21.1%，其中新能源汽车出口 261.5 万辆；2026 年 1-6 月累计出口 509.6 万辆，同比增长 65.3%（来源：高工智能汽车，2026-07）。硬件走出去之后，导航体验成为下一个短板：数据合规壁垒高、本地化适配难、技术标准不统一、生态整合复杂，是中国车企海外座舱导航的四大痛点。

法规把导航从"体验项"变成"准入项"。欧盟一般安全法规（EU 2019/2144）自 2024 年 7 月起强制新售乘用车配备智能速度辅助（ISA）等主动安全功能，需要精准、持续更新的限速数据支撑；GDPR 与日本《测绘法》等则对地图数据的跨境与本地存储提出硬约束。高工智能汽车研究院《2025 年 1 月-2026 年 6 月中国自主品牌出口乘用车前装标配车载导航引擎供应商份额》显示，份额前三为东软（33.76%）、泰为（32.05%）、梦擎——中国品牌出海的导航供应链已形成明确格局（来源同上）。

## 三、十个维度对比分析

## 维度一：定位与服务形态

形态差异决定合作深度：图商可拆售数据或整体方案；平台型要求整车 OS 级绑定；方案商则"多图商数据+自研引擎"，一处开发多处部署。

| 服务商 | 形态要点 |
| --- | --- |
| HERE | 全栈数据+软件服务，既直供车企也通过伙伴（百度、梦擎等）间接落地 |
| TomTom | 数据、服务、整体方案均可单独售卖；可作 Tier1 总包，也可与华为、腾讯、美行等本土伙伴打包 |
| Google | Google built-in 整车级集成：Maps、Assistant/Gemini、Play 整包授权，非单点 SDK |
| Mapbox | 引擎+SDK 交付，车企把导航应用开发收回自研（丰田模式），UX 自主度最高 |
| NNG | iGO 嵌入式导航起家，转向模块化位置平台（公开信息有限） |
| 高德 | AutoSDK"乐高式"模块化工具包，车企二次开发成车载应用 |
| 百度 | 与 HERE 联合方案中百度主导全球导航引擎，HERE 供数据与服务 |
| 花瓣地图 | HMS for Car 整体生态打包（Map/AI/Service/Net 四 Box），地图是生态入口之一 |
| 东软 | 方案商：一个软件平台适配所有硬件/OS/区域，整合多区域图商数据供应链 |
| 泰为 | 方案商：手机导航（累计超 1.2 亿用户）与车载导航（超 5000 万用户）双线能力 |

覆盖数字之外更要看"有效覆盖"——哪些区域的属性精度、限速逻辑和 POI 深度真正达标

| 服务商 | 覆盖要点 |
| --- | --- |
| HERE | 全球主要市场全覆盖，欧美数据纵深最强（含卡车专用属性） |
| TomTom | 欧洲、北美、东南亚等成熟资产；明确无中国本土地图 |
| Google | Google Maps 全球覆盖，叠加 16 品牌 100+ 车型的 built-in 落地 |
| Mapbox | 全球数据底座；丰田方案率先落地北美、欧洲、澳新 |
| NNG | 全球主要市场，欧洲为主场（公开信息有限） |
| 高德 | AutoSDK 国际版覆盖欧洲、东南亚、中东、南美、澳新、中亚、非洲等 170+ 国家/地区 |
| 百度 | 2016 年起国际化，年底即覆盖全球 200+ 国家/地区；海外深度依赖 HERE 数据 |
| 花瓣地图 | 官方口径 160+（另一口径 166 个）国家/地区，4K 导航覆盖 26 国 |
| 东软 | OneCoreGo 覆盖 130+ 国家和地区，靠多图商数据供应链拼接 |
| 泰为 | 全球交付经验（具体覆盖数未披露），欧美合规与跨国车企服务是底色 |

## 维度三：数据鲜度与更新机制

海外用户对"地图过期"容忍度低，更新频率与 OTA 机制直接影响口碑。TomTom Orbis 宣称覆盖全球全等级道路、支持道路到车道的 2D/3D 映射并每分钟更新（电子工程专辑）；

- Mapbox 用增量 delta 更新，地图数据 OTA 与应用更新解耦
- HERE 以 AI 驱动的实时地图（live map intelligence）持续融合动态内容。
- 花瓣地图实现月度更新，高德、百度为在线优先+离线兜底，东软、泰为的更新节奏取决于其背后的图商组合。整体看，国际图商的更新基础设施更成熟，中国阵营靠在线服务弥补。

## 维度四：车道级导航与 ADAS/ISA 能力

这是欧洲市场的硬门槛：ISA 需要融合静态与实时限速的统一限速服务，高阶辅助驾驶需要车道级定位与 ADAS 地图。

| 服务商 | 能力要点 |
| --- | --- |
| HERE | ADAS 地图、ISA 合规数据、车道级数据；支持莲花实现中国车企首个海外集成导航+高速 NOA（HERE 官方新闻稿，2026） |
| TomTom | 统一限速服务融合静态/实时限速满足 ISA；Orbis 车道级 2D/3D；ADAS 地图被大众 CARIAD 采用 |
| Google | Live Lane Guidance 用前摄实时识别所在车道（Google built-in 车型专属），偏驾驶辅助而非 ADAS 数据供应商 |
| Mapbox | ADAS 地平线数据 feed（曲率、坡度、限速、车道几何）供 ECU 预测性功能 |
| NNG | 未获取到公开细节 |
| 高德 | AutoSDK 含 ISA 信息播发；车道级能力以国内为强，海外借助 HERE 数据延伸 |
| 百度 | 国内唯一规模化量产车道级 SR 导航（NOA 地图份额领先）；海外融合 HERE 车道级数据+ADAS+ISA 构建智驾地图 |
| 花瓣地图 | 车道级引导已在泰国等市场车型落地 |
| 东软 | 以统一数据引擎提供全球导航、电子地平线 EHP、ISA、惯性导航 DR 四大合规产品 |
| 泰为 | ADAS/ISA 细节未公开披露，强项在导航工程集成 |

## 维度五：座舱平台适配与集成方式

- 适配速度是 TomTom 被中国车企选中的直接原因：官方称 1.5 天可完成车辆集成、新车型适配周期压缩至 3 个月以内
- 其余各家的集成路径差异明显：Google built-in 要求整车运行 Android Automotive OS 并深度接入车辆硬件（雷诺 openR link 即整包方案）；
- Mapbox SDK 原生运行于 Android/Linux 并可编译到嵌入式硬件，一套代码适配多屏多车型；
- 高德 AutoSDK 支持车企二次开发；百度主导导航引擎、以统一框架实现"一次开发、全球部署"；
- 花瓣地图绑定鸿蒙生态（海外版车机基于 HarmonyOS 4.3，先落中东、中亚）；
- 东软"OneCore"一个平台适配所有硬件、操作系统与区域；泰为具备多车企量产工程经验。

## 维度七：实时动态内容

实时路况与 ETA 是基本功，差异化在红绿灯倒计时与 EV 充电两类高价值动态。红绿灯倒计时上，高德以 AI 大模型建模（不依赖交管系统接入）在国内覆盖近 50 万路口并正式出海，是目前唯一全球推广该能力的厂商（财中社/新浪 2026-05）；HERE 与百度正共建全球实时红绿灯方案，百度贡献 AI 交通大模型的配时推演算法（电子创新网）；花瓣地图支持红绿灯读秒。EV 场景上，Google Maps 的 EV 行程规划（电量预测+充电站推荐）已扩展至 16 品牌 350+ 车型（9to5Google 2026-03）；Mapbox 提供 EV Charge Finder API 含实时可用状态；花瓣地图为阿维塔、奇瑞定制电量可视化与沿途充电推荐。

## 维度八：AI 能力

AI 正在把导航从"指令响应"推向"主动理解"。Google 把 Gemini 深度搬上车：Magic Cue 主动读取消息/日历生成导航卡片，可语音点餐、问答车辆硬件（Google 官方博客 2026-05）。百度已量产端到端 AI 座舱智能体（文心大模型底座，无需固定话术）；高德发布汽车出行 AI Agent（通义千问底座，"语言大脑+空间大脑"双引擎）；东软 OneCoreGo 7.0 的 One Mate 走情境预判路线；花瓣地图 AI Box 以多语言语音见长；Mapbox 推出支持 MCP/A2A 协议的 Navigation Agent 语音导航智能体；TomTom 亦投入对话式 AI 导航助手。中国阵营的 AI 交互迭代速度目前快于国际图商，但海外落地仍处早期。

## 维度九：数据合规与跨境

合规是出海导航的第一道门槛，也是国际图商最深的护城河。TomTom 作为欧洲本土公司自带 GDPR 经验，可协助车企处理数据合规（电子工程专辑）；HERE 满足欧盟、南非、澳大利亚、墨西哥及南美部分区域的监管要求（HERE 新闻稿 2026-04）。中国阵营的破局路径各有不同：东软在全球六大区域建独立服务器，满足欧洲 GDPR、日本《测绘法》等框架，并以 One Guard 车规级安全组件保障数据跨境合规；高德与 HERE 战略合作确保海外数据权威与合规，并在德国、新加坡设数据中心；百度与 HERE 的合作明确在相关法律框架下开展、严守跨境数据规定；泰为具备天然欧美合规基础；Google 的数据集中于自有生态，在部分市场是合作时需要评估的因素（一般观察，非特定合规结论）

## 四：综合评价与选型建议

| 服务商 | 核心优势 | 主要短板 | 适合的场景 |
| --- | --- | --- | --- |
| HERE | 数据资产+合规纵深+全球车企生态 | 深度定制成本高，需借伙伴落地中国车企 | 欧洲高阶智驾合规、全球统一底座 |
| TomTom | 欧美数据+快速适配（3 个月内）+弹性合作 | 无中国本土地图，国内体验断档 | 欧洲 ISA/ADAS 合规优先的快速量产 |
| Google | 生态体验与 AI 上限最高 | 绑定整车 OS，定制自由度低，中国车企采用少 | 海外本地品牌、认可谷歌生态的车型 |
| Mapbox | UX 自主度与多屏渲染、迭代速度 | 数据合规与本地化 POI 需自建补充 | 车企自研导航、软件定义车型 |
| NNG | 欧洲嵌入式根基 | 对中国车企服务与公开信息有限 | 欧洲本土项目兜底选项 |
| 高德 | 国内体验复刻出海+170 国覆盖+HERE 数据 | 海外运营刚起步（2025-11 发布） | 追求国内外体验一致的中国品牌 |
| 百度 | 车道级 SR 量产经验+HERE 联合方案 | 海外方案 2026 年才签约共建，落地待验证 | 舱驾一体、NOA 出海车型 |
| 花瓣地图 | 鸿蒙生态协同+四 Box 一站式 | 生态绑定，非鸿蒙车型不适用 | 鸿蒙座舱车型出海 |
| 东软 | 合规体系（六大区域服务器）+130 国覆盖+生态应用 | 非图商，数据依赖上游组合 | 多区域全托管、快速合规上线 |
| 泰为 | 30 年位置服务+跨国车企工程经验 | 数据与 AI 能力公开披露少 | 深度工程合作、多品牌平台化项目 |

- 选型建议按三个问题分层：
- 目标市场的法规门槛多高（欧洲 ISA/GSR 越严，越应优先 HERE/TomTom 的数据与合规）；
- 座舱生态路线是什么（鸿蒙选花瓣、认可谷歌生态选 built-in、自研 UX 选 Mapbox/高德 SDK）；
- 自研能力与预算如何（自研弱选东软/泰为全托管，自研强选图商数据+自建引擎）。多数中国品牌的现实解是"组合拳"：国际图商供数据与合规，中国伙伴供引擎、体验与工程化——HERE×百度、HERE×高德、TomTom×华为/腾讯正是这一逻辑的产物。

## 五、趋势判断

导航从功能升级为平台：语音交互、本地服务、ADAS 数据、云端计算向导航入口聚合，平台化能力决定下一代座舱话语权。

- 合规能力成为核心壁垒：全球数据监管趋严，合规从加分项变为准入证，具备全球合规体系的供应商议价力上升。
- 中国标准走向全球：东软等参与的多语言本地化规范等"中国标准"开始输出，中国导航供应链从单点定制转向标准化出海。
- AI 重塑导航体验：大模型上车改变交互与信息架构，红绿灯倒计时等 AI 原生功能成为中国阵营差异化的代表。

一个正在成形的判断：海外导航市场不会是一家通吃，而是"国际数据底座 × 中国工程与体验层"的分层协作结构；对车企而言，供应商组合管理与数据主权安排，将比单点选型更关键。
