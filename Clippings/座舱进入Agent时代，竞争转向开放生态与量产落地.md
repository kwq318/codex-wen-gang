2026 年被不少行业媒体称为汽车 AI Agent 的落地元年。

华为、小米、比亚迪、奔驰、宝马 **在这一年集中亮出 Agent 座舱方案** ，发布会的重心从屏幕尺寸、芯片算力，齐刷刷转向一句话， **让车从会聊天变成会办事** 。

10 月 21 日讯飞发布星火智慧座舱 SparkAuto Space 3.0，官方定位为行业首个全模态类人交互座舱，核心是一个名为 Master Agent 的全车调度中枢。

布局 Agent 座舱的厂商远不止它一家，当全行业都开始讲 Agent， **差异已经不在演示视频里那句更自然的对话** ，而在 **三道此前被营销掩盖的硬门槛** 上，模型能不能在量产车规硬件上跑起来，能不能真正打通底层车控，能不能调动真实世界的服务把事办完。

讯飞手里的牌、以及它选择的打法， **恰好可以当作观察这一代座舱竞争的一个样本** 。

01

Agent 不是换个说法

过去两年的大模型上车， **有一段行业心照不宣的空窗期** 。

2024 年前后几乎所有车企都在发布会上讲大模型座舱，但据多位座舱工程师在媒体上的复盘， **当时多数方案只是在外层调用一个通用大模型 API** ，底层车控沿用原有语音链路， **两三个月即可完成适配上车** 。

结果是车机更能聊了，却很难真正连贯地控车，行业把这种状态 **概括为能聊天、干不了事** 。

**Agent 要补上的正是执行这一环** 。

它要求系统把一句模糊诉求 **拆成多个带约束、有先后的子任务** ，自主规划并调用车辆和外部能力执行到底。

**这不再是套一层对话模型能解决的** ，背后需要几项此前不具备的工程条件。

中央计算加 SOA 服务化架构，把灯光、空调、底盘等硬件封装成 **上千个可调用的原子接口** ； **线控底盘规模化量产** ，让指令有了能精确执行的执行器；再加上分级权限体系，决定哪些动作 Agent 可以自行决定、哪些必须请求确认。

中国汽车工程学会在《2025 年汽车智能座舱技术趋势》中也把端到端 AI 智能体的初步应用列为主线，判断其正 **从语音助手演进为具备长程推理、主动服务能力的座舱中枢** 。

理解了这个背景，才能看清讯飞星火智慧座舱 3.0 真正在补什么。

Master Agent 对外呈现为一个统一入口，对内被拆成意图理解、任务规划、任务调度和任务监督四项职能，目标是让交互的基本单位 **从一句指令变成一件完整任务** 。

比如同时要求寻找评分高、人少的川菜馆并订好晚间电影票，系统要自己判断找餐厅与选影院可以并行，订座要核对营业时间，购票排在饭后场次，中途来电还要决定任务如何暂停避让。

**这种多任务并行、依赖与冲突仲裁** ， **才是它和上一代问答式车机的实质分界** 。

02

端侧是道硬门槛

Agent 要实时、要安全， **就不可能把所有推理都交给云端** 。

![图片](https://mmbiz.qpic.cn/mmbiz_png/bn2UiaeAa1NUic8OnHO7SWkToyXccPbmMBFM3aTPYngIFLGBGv8p2pk2VEicT1R0hBRC6lTDTOEe6W8MqQn6gLNUhvmoHEhSBYiclEWcE7YfCZk/640?wx_fmt=png&from=appmsg#imgIndex=1)

地库和隧道的弱网断网场景下，开窗、空调这类车控若要等待网络回传，体验和安全都不成立，人脸、位置、对话等数据的 **隐私属性也要求相当一部分能力留在车端** 。

于是第一个工程矛盾出现了， **模型越大越聪明，但车规硬件的算力、内存、功耗和散热都被严格限制** 。

讯飞端侧模型 SparkAuto-EMM **覆盖 2B、4B、7B 多个尺寸** ，并推出 35B-A3B 多模态模型。

35B 是总参数规模，A3B 指借助 MoE 混合专家架构， **单次推理实际激活约 30 亿参数** ，从而在保留较大知识容量的同时压低单次推理的算力与内存开销， **正面回应端侧的内存墙** 。

讯飞还通过自研 MTP 草稿模型优化解码，官方称 **解码速度提升 1.8 倍** 。

**不过有一个数据需要辨明** ，讯飞在发布材料中给出的首帧响应 **低于 650 毫秒、峰值内存下降 75%** ，测试平台写的是英伟达 Jetson Thor T5000。

容易被忽略的是， **Jetson Thor 在英伟达产品体系里定位为面向机器人与边缘 AI 的计算模组** ，典型客户是人形机器人企业，与通过 ASIL-D 功能安全认证、用于整车的车规级 DRIVE Thor **并非同一条产品线** 。

因此 650 毫秒 **更适合被理解为高算力边缘平台上的工程验证结果** ，而不能直接等同于消费者在量产车里得到的响应表现， **真正决定走量体验的，是下面这套量产硬件** 。

讯飞为此配套了 SparkAuto BOX 硬件系列，简称 SABOX，分高低两档覆盖不同价格带。

走量档 SABOX-Lite 基于瑞芯微平台，搭载 4B 端侧模型并支持多片级联；高阶档 SABOX-Ultra 可承载 35B 模型。

**这里有一个比跑分更关键的产业细节** 。

瑞芯微官方方案显示，承担 AI 推理的 RK1828 是一颗内置高带宽内存的端侧 AI 协处理器，需与 RK3576M 等车规主控搭配， **官方将整套 AI Box 的 BOM 目标定在千元级** ，主打风冷、低时延和存量车型可扩展升级；面壁智能同样基于 RK3576M 加 RK1828 的组合，在端侧跑通 4B 全模态模型。

这说明两件事：

一， **把 4B 级多模态模型压进千元级硬件** 、让智能座舱从旗舰下放到走量车型，已经成为国产芯片加国产模型共同推动的明确路径， **讯飞踩在了趋势上** 。

二，这也意味着端侧 4B 能力正在快速平民化， **并不会成为某一家的长期护城河** 。

讯飞的 **相对优势不在单点芯片，而在软硬一体方案的成熟度** ，以及把同一套交互铺到不同价位、再叠加其车载渠道的整合能力。

03

把大脑开放给车企

如果说端侧解决的是能不能跑，那么更深一层的分歧，是 **这套智能体由谁定义、数据和品牌主权归谁** 。

这恰恰是当前座舱 AI 供应体系里最微妙的地方，也是讯飞把 Master Agent 本身拿出来共创的真正背景。

**现在向车企提供座舱 AI 的，大致是两类玩家** 。

一类是以豆包、通义千问为代表的互联网平台，依托通用大模型和云上中枢切入，模型迭代快、内容与服务生态强，2025 年豆包在新上市量产车型上的搭载量已冲到行业前列，通义也进入了多家主流车企的体系。

另一类则是传统语音与座舱 Tier1，强项在车规工程、前装量产和对车企流程的理解，讯飞属于后者。

对车企而言，接入平台型模型固然省事，但同一套通用大脑扩散到大量品牌之后， **自家车机如何保持性格差异** 、 **用户行为数据会不会沉淀在平台手中** ，是绕不开的顾虑。

讯飞的应对，是把最核心的 Master Agent 向车企开放共创， **传统供应商交付的往往是封装好的黑盒** ， **车企能改的多是唤醒词、音色和界面皮肤** ；而 MA 共创从底层工具介入，一直延伸到技术定义和智能体业务策略协同，车企全程参与定义、配置、联合验证与量产运营，记忆策略、任务排序和品牌性格都可以由车企写入，配合人格、形象、动作、声音、语言 **五维品牌人设定制和两千多个动作场景库** 。

**把最值钱的大脑定义权交出去** ，本质上是把智能化时代 **最容易被供应商收走的品牌主权留在车企一侧** ，这对于不甘心只做硬件外壳的主机厂有现实吸引力， **也是 Tier1 面对云厂商竞争时最合理的卡位** 。

支撑这种卡位的是存量渠道。

据盖世汽车研究院统计，2025 年中国车载语音交互装机市场中，科大讯飞 **以约 818.8 万套、41.9% 的份额位列第一** ， **领先第二名思必驰的 22.0%** 。

需要说明的是，这是语音交互的年度装机口径，反映的是前装渗透和量产交付的基本盘， **并不等同于 3.0 这类大模型智能体座舱的装车量** ，讯飞自报的 **累计前装超 8100 万辆、500 多款量产车型** 同样包含大量早期语音单点方案。

但渠道和量产经验确实是它把 Agent 快速铺进新车的跳板。

当然也要看到， **开放共创并不等于锁定客户** 。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/bn2UiaeAa1NXsubZnJ2ibCOMRj3KaQrw29HXzGbYMDIaxGiclWRlQ0diasibKdSrf6s38tlQLUcaP8XBOx5ROibbWATvU2Tu6bdWS89wUBmH7Gw0M/640?wx_fmt=webp&from=appmsg#imgIndex=2)

一个颇具代表性的细节是，讯飞 3.0 首批合作品牌中的奇瑞，同期也宣布将豆包大模型融入其自研智能体、面向全系车型适配。

车企采用 **多模型、多供应商并行已经成为常态** ，发布即量产、进入首批名单， **证明的是方案通过了车规与工程门槛，却不构成独家绑定** 。

这反而说明， **谁能在共创深度、量产稳定性和后续 OTA 运营上持续证明自己，谁才留得住车企** 。

星火智慧座舱 3.0 发布即量产，首批合作品牌包括奇瑞、长城魏牌和东风日产，交付的成色最终要由这几个品牌的量产车型来回答。

04

要替用户办事

**Agent 的价值落在执行** ，而执行所需的餐厅、票务、停车、充电、影音版权等能力， **没有一项掌握在车企或座舱供应商自己手里** 。

这解释了为什么前三代座舱可以回避生态问题，功能机不联网，联网车机靠应用市场让用户自行点选，问答式大模型只负责说， **唯独智能体必须调用真实世界里别人的能力** 。

就此而言， **开放生态构成了 Agent 成立的前提** ，已经超出锦上添花的意义。

讯飞的生态布局围绕对车企、对服务、对伙伴三条线展开，对车企是 MA 共创，对服务是琳琅平台。

琳琅用统一协议把第三方服务接入，再由 Master Agent 按场景拆分重组，对车企可定制、对用户可订阅， **目前接入 60 多个生态信源、600 多个上车项目** ，官方披露 **日均调用 2.2 亿次** 、 **沉淀 600 多条工作流** ，并启动琳琅荟萃计划，未来一年再引入一百多家伙伴。

相比应用孤岛式的旧车机，关键变化在于 **服务在底层被拆成可调度的原子能力** ，一句话背后可以是多个服务并行配合。

这次被摆到台前的三个伙伴，分别补上执行链条上不可替代的一环， **能看出是按链条而非按名气组合** 。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/bn2UiaeAa1NXvz6RvXFVRPDjRM7TiaWt4S8FrvQHn80LRRMdpZsfVtFTCpqMGbAicC64kWDBTIxlkq0weMjhWMWHtwJflHqvT0sPSdIP3H1j3w/640?wx_fmt=jpeg&from=appmsg#imgIndex=3)

支付宝补的是 **支付与履约这临门一脚** ，双方合作名为讯宝计划，星火座舱负责理解、判断与记忆，支付宝车载助手负责把事办完并理顺支付，高速不停车通行、离场免密支付、顺路取件、到店自动下单等动作才可能从建议走到代为成交， **这也是车载智能体最难跨越的一步** 。

腾讯音乐补的是内容源头， **空间音频算法再强也绕不开曲库与版权** ，双方在会员、音效、推荐上共创，iFLYSOUND 会员与 QQ 音乐超级会员打通，讯飞车载功放获得 **行业首个 QQ 音乐臻品音质认证** ；影音硬件上，AI 可把立体声实时 **重建为 7.1.4 全景声** ，并采用氮化镓声学架构 **减重约 30%** 。

瑞芯微补的则是前文所述的国产芯片底座。

**理解、支付、内容、算力四个环节被分别钉牢** ，智能体才有了真正办事的手脚。

**车机出海的难点不在直译** ，而在理解当地语言的模糊表达、满足当地法规与隐私要求。

讯飞座舱 **支持 32 门外语、覆盖 60 个国家和地区** ，在全球六大区域设属地团队，官方披露 **80% 的出海新车型选择其方案** ，并搭建 **敏感输入拦截、意图过滤、动态护栏与云端干预四层防护** 。

它还联合行业编制全模态座舱白皮书与测评标准，试图 **把评价口径从功能数量拉回真实体验** ，一个供应商主动推动体验测评。

这也意味着愿意让自己的量产表现接受同一把尺子的衡量。

写在最后

把这一代座舱放回行业脉络里，结论会比较冷静。

**感知和表达侧的能力正被大模型快速拉平** ，多模交互的领先窗口越来越短， **真正的分水岭已经移到执行侧** ，谁能让智能体调动真实服务，并把整套能力稳定、低成本、合规地批量装进不同品牌和价位的车里。

讯飞的选择，是 **用 Tier1 的方式打这场 Agent 之战** 。

一端靠瑞芯微这样的国产芯片把端侧 4B 铺进主流价位，靠 41.9% 份额对应的前装渠道承接量产；

一端把 Master Agent 开放给车企共创，用品牌主权差异化回应互联网平台的云上模式；再用琳琅、支付宝和腾讯音乐把办事所需的服务、支付与内容补齐，并用出海合规能力延伸到海外。

**这套组合的长处是落地和开放，短板同样清晰** ，通用大模型底座仍要面对豆包、通义的快速迭代，发布会上的高算力平台数据 **也有待量产车实测兑现** 。

Agent 元年从来不缺演示， **缺的是量产之后用户是否真的敢把一件件正事托付给车** 。

这个问题的答案，不会出现在任何一场发布会上，而在奇瑞、长城魏牌和东风日产的车型陆续上路之后。
