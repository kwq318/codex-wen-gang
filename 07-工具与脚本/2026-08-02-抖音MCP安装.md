# 安装抖音 MCP（Douyin_Spider）

**日期**：2026-08-02
**状态**：已决定

## 背景

> 用户希望把 `gcv-cat/DouYin_Spider.git` 安装为 Codex 可调用的抖音 MCP。

## 关键发现

- GitHub 上实际仓库为 `ccv-cat/Douyin_Spider`，是一个抖音爬虫/API 封装项目，本身不包含 MCP 服务端。
- 因此本次安装采用“原仓库 + 本地 MCP 包装层”方案，而非直接注册仓库入口。

## 决策

1. 使用 `ccv-cat/Douyin_Spider` 作为抖音 API 底层。
2. 新增 `mcp_server.py` 作为 stdio MCP 服务端，暴露搜索、作品、用户、评论、直播、通知、互动等 14 个工具。
3. 将服务端安装到 `~/.codex/mcp-servers/Douyin_Spider/`，并在 Codex 全局配置中注册为 `douyin`。
4. Cookie 通过安装目录下 `.env` 的 `DY_COOKIES` / `DY_LIVE_COOKIES` 配置，不写入 Codex 配置。

## 影响范围

- Codex 全局 MCP：`douyin`
- 安装路径：`~/.codex/mcp-servers/Douyin_Spider/`
- 运行依赖：Python 3.9 venv + Node.js 签名依赖
