# 销售研究检查清单

## 研究范围

- [ ] 明确公司名称、域名、地区和研究截止日期
- [ ] 明确产品、目标客户、销售阶段和研究目的
- [ ] 明确目标联系人或待寻找的职位
- [ ] 明确时间窗口，默认优先最近十二个月

## 公司信息

- [ ] 业务、行业、客户对象和商业模式
- [ ] 总部、关键地点、成立时间和规模线索
- [ ] 产品、用例、定价、合作伙伴或集成
- [ ] 融资、并购、领导层、发布和扩张
- [ ] 相关招聘及招聘中的工具、流程和职责
- [ ] 技术栈证据及证据等级
- [ ] 可能的效率、增长、风险、合规或数据痛点

## 联系人信息

- [ ] 当前职位和任职时间
- [ ] 职责范围及与目标用例的关系
- [ ] 可核验的职业经历和公开专业内容
- [ ] 可能的使用者、影响者、经济买方和评审者
- [ ] 适合引用的近期发言、文章、演讲或项目
- [ ] 同名、离职或职位信息冲突已排除或标注

## 证据质量

- [ ] 重要事实有一手来源或可靠交叉验证
- [ ] 每条近期信息有具体日期
- [ ] 事实、推断和行动分开
- [ ] 没有把信息缺失写成否定事实
- [ ] 没有编造数据、联系方式或决策权
- [ ] 没有收集与销售无关的敏感个人信息

## 交付质量

- [ ] 一句话结论清晰
- [ ] 购买信号有强度、关联和推荐动作
- [ ] 个性化切入点不超过三条且基于事实
- [ ] 建议问题能验证关键假设
- [ ] 下一步包含对象、时机、渠道和退出条件
- [ ] 列出信息缺口、冲突来源、可信度和研究截止日期
