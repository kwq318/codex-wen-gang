## 二、先天优势：艾拉比的关系基础

艾拉比是东风汽车的**已认证供应商**：

- **2024年9月** 荣获东风汽车研发总院「研发创新奖」，被评为年度优秀供应商
- 服务内容：OTA远程升级、远程诊断
- 合作深度：已进入东风研发总院供应商体系，有直接技术对接通道

**这意味着艾博连不是从零开始的冷拜访。** 艾拉比的OTA通道是最自然的切入点——座舱软件需要OTA推送，Agent平台的升级迭代同样依赖OTA基础设施。从OTA延伸到座舱AI方案，是一步之遥。

## 三、竞争对手在东风体系内的位置

| 供应商 | 在东风的位置 | 对艾博连的威胁 |
|--------|-------------|---------------|
| **华为** | 岚图、猛士、奕派核心座舱+智驾供应商，奕境品牌共建方 | 最大威胁，几乎垄断高端品牌座舱 |
| **斑马智行** | 东风合作过（AliOS），但目前未见深度绑定 | 潜在竞争者，有量产规模优势 |
| **百度** | 座舱大模型方案，通用性强 | 可能在风神/纳米品牌竞争 |
| **自研** | 天元智舱Plus国产化方案 | 对中低端品牌有自研替代趋势 |

**核心判断**：华为是东风智能座舱的「骨架」，艾博连的机会不在于替代华为，而在于成为「肌肉和皮肤」——在已有硬件和OS之上提供差异化的Agent体验层和场景化应用。

## 四、切入策略

### 4.1 核心逻辑：不替代，只增强

东风的鸿蒙座舱和天元智舱是基础设施。艾博连的Agent平台是**上层的场景体验引擎**，可以与华为鸿蒙、天元智舱并行部署。

### 4.2 首选切入点：奕派品牌

**理由**：
- 奕派定位「主流智能」，2026年计划3款新车，处于产品快速扩张期
- 虽然宣布搭载鸿蒙座舱，但处于「宣布」到「量产」之间，方案细节仍有调整空间
- 奕派面向年轻用户，「千人千面」个性化正是艾博连核心卖点
- 奕派有一款2026Q3发布的「旗舰六座SUV」（搭载华为全栈），可以作为高端合作标杆

### 4.3 次选：岚图品牌

**理由**：
- 岚图有自研逍遥座舱AI，证明他们对座舱AI有独立掌控意愿
- 岚图FE（2026年中发布的FUV）面向年轻用户，强调「超越预期的个性化」——与艾博连理念高度契合
- 岚图已经接入了DeepSeek，但多模型融合本来就是艾博连的强项

### 4.4 中低端补充：风神/纳米

**理由**：
- 天元智舱Lite方案主打成本控制
- 艾博连的「场景工厂」低代码方案可以低成本赋能中低端车型
- 竞争压力小（华为不碰这个价位段）

## 六、行动计划（6个月）

### 第一阶段：情报验证期（1-2周）

- [ ] 通过艾拉比客户关系，了解东风研发总院当前智能座舱供应商评估节奏
- [ ] 确认奕派2026Q3旗舰六座SUV的座舱方案是否已锁定
- [ ] 调研东风「智能座舱人力支持项目」中标结果，了解东风当前座舱AI的人力缺口
- [ ] 分析岚图逍遥座舱AI的技术公开信息，定位差异化空间

### 第二阶段：技术破冰期（3-4周）

- [ ] 制作定制化Demo：基于奕派/岚图现有鸿蒙座舱，叠加艾博连Agent平台的体验增强演示
- [ ] 重点展示三个差异化功能：
  1. **忆停车**：完整可演示的停车场→入场→离场闭环
  2. **场景Agent动态生成**：演示如何在不改动底层OS的情况下，快速生成新的场景Agent
  3. **多模型融合能力**：展示智谱GLM + DeepSeek双模型协同
- [ ] 联合艾拉比，以「OTA + 座舱AI」整体方案的形式向研发总院提案
- [ ] 争取参加下一次「走进东风」技术日活动

### 第三阶段：定点突破期（5-8周）

- [ ] 目标：获得一个品牌的一款车型的试点/预研合作机会
- [ ] 提案策略：
  - **奕派**：主打「年轻化场景体验 + 量产效率」（场景工厂低代码让车企自己快速生成场景Agent）
  - **岚图**：主打「超越预期的个性化」- 用智谱GLM的多模态能力增强逍遥座舱
  - **海外市场**：东风正在推进全球化（猛士宣布出海），艾博连的GDPR合规方案 + 华为HMS海外生态是差异化武器

### 第四阶段：标杆建立期（9-12周）

- [ ] 拿到首个试点项目
- [ ] 建立东风-艾博连联合创新实验室（参考奇瑞雄狮LIONAI模式）
- [ ] 推动试点成果在2027年新车型上量产搭载

### 第五阶段：规模复制期（3-6个月）

- [ ] 从试点品牌向其他品牌横向复制
- [ ] 争取进入东风天元智舱的生态伙伴目录
- [ ] 推动独立融资完成，以东风合作为标杆案例

## 七、核心话术框架

### 7.1 破冰话术（对研发总院）

> 「东风在头部品牌的智能化已经走得很前面了——鸿蒙座舱、天元智舱、DeepSeek全系接入。但我们在和奇瑞、长城合作中发现一个共性挑战：当底层OS和AI大模型都就位之后，座舱体验的差异化反而更难做了——因为大家都在用同一套东西。我们的角色不是再给你一个OS，而是一个Agent工厂，让你的产品经理和场景设计师能像搭积木一样快速创建千人千面的座舱体验。」

### 7.2 差异化话术（三个不可替代性）

| 卖点 | 话术 |
|------|------|
| **不大动干戈** | Agent平台运行在现有OS之上，不需要改造鸿蒙或天元智舱的底层架构，接入周期降到8-12周 |
| **多模型自由** | 不锁定任何一家大模型——DeepSeek、智谱GLM、腾讯混元都能接入，东风保留选择权 |
| **已验证量产** | 已获奇瑞雄狮LIONAI实验室入驻，量产方案2026H2落地，不是PPT |

### 7.3 针对华为合作的精准回应

> 「华为是我们尊敬的合作伙伴，不是竞争对手。鸿蒙座舱解决的是『骨骼和器官』问题——OS、芯片、智驾感知。艾博连解决的是『神经系统』问题——让这些器官能协同思考、主动服务。我们的Agent已经在奇瑞的华为座舱方案上跑通了，证明两者不是替代关系，是协同关系。」
