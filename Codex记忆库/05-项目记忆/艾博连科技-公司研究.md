# 艾博连科技（AI-Link）公司研究

## 一、执行摘要

艾博连科技（AI-Link）是由上海艾拉比智能科技有限公司（OTA 头部供应商）100% 孵化的智能座舱 AI Agent 平台公司。2024年6月正式运营，核心定位是将 AI 大模型深度应用于车载座舱，为主机厂提供从感知、决策到服务的端到端 Agent 平台。2026年是量产落地的关键年份。

## 四、产品体系

### 4.1 核心平台：AI-Link 智能座舱 Agent 平台

感知→决策→服务→反馈 四层架构，打通地图/语音/应用/车控等分散能力，构建统一服务决策中枢。

- **感知层**：多模态融合感知（语音、手势、视觉、环境传感器）
- **决策层**：场景模式生成工厂 + 场景仿真Agent验证
- **服务层**：跨模块/跨服务协同与复杂场景闭环
- **反馈层**：用户行为学习与持续迭代

### 4.2 四大核心模块

| 模块 | 成熟度 | 核心能力 |
|------|--------|----------|
| **生成式HMI交互** | 量产准备 | 动态卡片、Gen-UI智能交互、4K高清主题4秒极速生成，资源占用率约0.1%，适配99%车企屏幕 |
| **AI听说+视触模块** | 量产准备 | 多模态场景识别，通勤/亲子/商务/灾害预警等全场景覆盖 |
| **忆停车** | 已具备量产能力 | 入场自动标定→离场无感支付全流程闭环，车机+手机端协同 |
| **全球化座舱方案** | 联合预研中 | GDPR/PDPA合规，与华为HMS For Car联合预研，地图/语音/应用生态三合一平台化 |

### 4.3 端侧语音基座模型

基于基座模型裁剪开发的端侧大模型，关键指标：
- 三段式语音处理简化为两段式
- 识别率目标 99%
- Token 生成速度 100 tokens/s
- 首次响应时间 < 800ms
- 超拟人 TTS，支持声音复刻
- 未来支持 100+ 国家语言
- 弱网/无网场景高可用

### 奇瑞 LionCarmind 合作进展

艾博连定位为车载 AI-Agent 智能座舱软件服务商，此前已加入奇瑞雄狮 LION AI 联合实验室，并对接 LionCarmind 生态开展技术协同。当前合作状态：

- **已量产**：自研 AI 寻车产品已在 Carmind 1.0 实现量产
- **进行中**：正在对接奇瑞 8397 平台 AI 座舱项目，方案后续可兼容 8255 平台
- **海外延伸**：艾博连具备海外合规与本地化适配能力，可支撑奇瑞海外车型在地图、语音和全球生态的大模型化升级
- **生态基础**：自研座舱 Agent 平台、生成式 HMI、端侧感知记忆等车规级量产方案，已获多家主机厂定点；与华为、腾讯建立生态合作，重点布局海外市场

## 七、竞品对标分析

| 竞品 | 核心差异 | 对艾博连的威胁 | 艾博连的对应优势 |
|------|----------|----------------|------------------|
| **斑马智行**（AliOS+元神AI，1000万+搭载量） | 自有OS+AI深度融合，最大装机量 | 高——品牌+装机量碾压 | 轻量级 Agent，无OS绑定，适配鸿蒙/天元等 |
| **百度座舱大模型**（文心+30+Agent） | 百度AI生态全覆盖 | 高——技术+数据+地图生态优势 | 场景工厂低代码模式，比百度更灵活 |
| **亿咖通**（吉利系，软硬一体） | 吉利内部资源+软硬一体 | 中——绑定吉利体系 | 可跨品牌独立部署，不绑定单一车企 |
| **星河智联**（广汽+科大讯飞合资） | 讯飞语音底座+广汽渠道 | 中——区域绑定 | 更开放的Agent生态，不只绑定一家 |
| **光庭信息**（智枢AI座舱，UE5） | 自研Kustom3D框架+OpenClaw生态 | 低——偏视觉HMI | Agent闭环+场景工厂是差异化壁垒 |
| **博泰车联网**（全域AI智能座舱） | 多年座舱经验+车企关系 | 中 | 艾博连AI Agent 平台更专注大模型原生 |

**核心判断**：艾博连差异化在于「场景工厂」（低代码场景编辑）和「Agent 闭环」（感知-决策-服务-反馈四层），国内座舱 Agent 能做实场景编辑器的极少。

## 八、优势、风险与挑战

### 核心优势
1. **母公司通道**：艾拉比已有成熟车企渠道和信任背书，这是新创公司最稀缺的资源
2. **团队经验**：CEO和CTO来自腾讯音乐/腾讯游戏 + 小马立行，有量产交付经验
3. **独立定位**：不绑定单一OS或品牌，可跨平台部署（鸿蒙/天元/自研OS）
4. **差异化技术**：场景工厂（提升80%开发效率）、端侧语音模型、生成式HMI
5. **生态开放**：同时对接智谱GLM、腾讯混元、华为HMS，不站队

### 核心风险
1. **融资不确定性**：2025年3月启动独立融资，截至目前仍未完成，融资窗口期正在收窄
2. **量产验证压力**：2026H2 量产落地是关键节点，一旦跳票或交付质量不达标，品牌信任何时恢复不确定
3. **品牌知名度低**：对比斑马、百度、亿咖通，行业认知度明显不足
4. **人才竞争**：AI座舱人才被大厂和车企争抢，小公司留人压力大
5. **依赖母公司**：被视作艾拉比的子公司，独立品牌认知建立需要时间

### 市场风险
- 主机厂自研座舱AI的趋势正在加速（如东风天元智舱、奇瑞CheryAgent）
- 华为鸿蒙座舱市占率持续扩大，封闭生态可能挤压第三方空间
- AI大模型快速迭代，今天的领先能力半年后可能被追平
- 竞品也都在做Agent（百度/斑马/高通Claw）

## 九、战略建议

### 面向主机厂销售时的关键定位
- **不替代华为/鸿蒙**——「艾博连是在华为底座上跑的神经系统，不是骨骼」
- **差异化卖点**：场景工厂（低代码场景编辑器，解决主机厂场景定义效率问题）
- **降本叙事**：缩短开发周期 + 减少场景开发人力投入
- **开门方式**：通过艾拉比的OTA渠道切入，再做AI方案增购

### 需要重点回答的客户问题
1. 「你们和华为鸿蒙的关系是什么？」→ 神经系统 vs 骨架，已在奇瑞华为方案上验证
2. 「你们和艾拉比是什么关系？」→ 独立运营的子公司，共用渠道
3. 「量产了吗？」→ 已配套吉利/问界/北汽/红旗等10+款车型（热管理AI智控），AI寻车已在奇瑞 Carmind 1.0 量产，Agent平台2026H2量产
4. 「融资完成了没？」→ 正在推进中（诚实告知）
5. 「你们和斑马/百度比有什么不同？」→ 独立于OS，灵活部署，场景工厂是独家能力

### 竞争策略建议
- **正面战场**：抓住 2026H2 量产窗口，先拿下1-2个标杆车型的全栈Agent合作
- **差异化战场**：场景工厂（低代码）+ 端侧语音模型 + 全球化合规方案（GDPR/PDPA）
- **避开**：和华为在鸿蒙生态内正面竞争，不和斑马比装机量
- **利用**：母公司艾拉比的 OTA 渠道做交叉销售
