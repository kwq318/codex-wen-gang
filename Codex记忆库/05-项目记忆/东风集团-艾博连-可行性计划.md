# 东风集团 × 艾博连科技 可行性计划

## 一、核心假设验证

### 假设 1：艾拉比的 OTA 通道是艾博连最自然的入口

| 验证维度 | 判断 | 依据 |
|----------|------|------|
| 供应商关系 | 已确认 | 2024年9月获东风研发总院「研发创新奖」，年度优秀供应商 |
| OTA 与座舱 Agent 的关联性 | 强关联 | 座舱 Agent 的场景包、HMI 主题、模型参数都需要 OTA 推送 |
| 联合提案的合理性 | 合理 | 东风研发总院已对艾拉比建立技术信任，从 OTA 延伸到座舱 AI 路径最短 |

**判断：假设成立。艾拉比关系是切入点，不是替代性竞争。**

### 假设 2：「体验增强层」定位能绕过华为锁定

| 验证维度 | 判断 | 依据 |
|----------|------|------|
| 华为在东风的技术边界 | 骨架层 | 鸿蒙座舱是底层基础设施，并非应用层 |
| 艾博连的技术边界 | 神经系统 | Agent 平台运行在 OS 之上，无需改造底层 |
| 共存验证 | 已有先例 | 艾博连 Agent 已在奇瑞的华为座舱方案上跑通 |
| 东风对上层差异化的需求 | 强烈 | 全系接入 DeepSeek 说明东风在意 AI 体验差异化 |

**判断：假设成立。关键在于第一次沟通时精准定位——「不替代，只增强」。**

### 假设 3：奕派是最佳切入点

| 维度 | 有利 | 不利 |
|------|------|------|
| 产品阶段 | 2026年3款新车快速扩张期，方案可能尚未完全冻结 | 已宣布搭载鸿蒙座舱+乾崑智驾 |
| 目标用户 | 年轻化、强调个性化 | — |
| 决策窗口 | Q3 旗舰六座SUV方案细节仍有调整空间 | 越接近量产窗口越小 |
| 竞争密度 | 华为锁定高端，奕派仍在定型 | — |

**判断：奕派是首选，但窗口期有限（约6-8周）。岚图作为备选必须同步推进。**

## 二、三个差异化场景的可行性与 Demo 路径

### 场景 1：忆停车（最高成熟度）

| 维度 | 评估 |
|------|------|
| 成熟度 | 已具备量产能力 |
| 差异化强度 | 高——停车是高频痛点，能覆盖全流程的产品极少 |
| Demo 难度 | 低——可直接在车内或模拟环境演示完整闭环 |
| 策略 | 带一台已集成忆停车 Demo 的测试设备，现场演示完整流程 |

### 场景 2：场景 Agent 低代码工厂（最高差异化）

| 维度 | 评估 |
|------|------|
| 成熟度 | 规划中，未量产 |
| 差异化强度 | 极高——国内座舱 Agent 能做低代码场景编辑器的目前只有艾博连 |
| Demo 难度 | 中——需搭建场景编辑器原型界面，前端 Demo 即可打动产品经理 |
| 策略 | 5 分钟交互式 Demo：拖拽卡片→选择触发条件→生成新 Agent→OTA 推送→车机变化 |
| 前置条件 | 需要一个可在任意设备上运行的场景编辑原型 |

### 场景 3：多模型融合（技术壁垒最高）

| 维度 | 评估 |
|------|------|
| 成熟度 | 智谱 GLM 已合作，技术路径可行 |
| 差异化强度 | 高——主流玩家绑定单一大模型，多模型路由+编排是技术壁垒 |
| Demo 难度 | 高——需要后端多模型网关和真实推理集群支持 |
| 策略 | A/B 对比 Demo：单一模型 vs 多模型协同，同一场景请求的处理效果差异 |
| 前置条件 | 需部署了多模型网关的 Demo 环境（至少接入 DeepSeek + 智谱 GLM） |

### 优先级排序

| 优先级 | 场景 | 理由 |
|--------|------|------|
| P0 | 忆停车 | 成熟度最高、演示风险最低、闭环感最强 |
| P1 | 场景 Agent 低代码工厂 | 差异化最大、最能打动产品决策者 |
| P2 | 多模型融合 | 技术壁垒最高，作为二次拜访的技术深挖话题 |

## 三、切入路径决策树

问：奕派 Q3 旗舰六座SUV 座舱方案是否已完全锁定？

- 否（尚未锁定）- 最优路径
  - 短期：以「体验增强层」定位争取 POC 试点
  - 中期：6-8周内完成 Demo 验证 → 进入量产评估
  - 关键动作：通过艾拉比渠道快速安排技术交流

- 是（已锁定华为全栈，含应用层）- 常规路径
  - 对策 1：转为「预研合作/联合创新实验室」模式，目标 2027 年车型
  - 对策 2：转向岚图品牌（自研逍遥座舱 AI，接口更开放）
  - 对策 3：联合华为，以 HMS For Car 海外 Agent 为切入点

- 部分锁定（华为提供骨架，应用层/场景层开放）
  - 最佳平衡状态
  - 无需替代华为，只需做引擎层以上的 Agent 编排
  - 切入点：帮助奕派「在华为底座上快速生成奕派专属场景」

**黄金路径**：最可能的场景是「部分锁定」——华为提供 OS/芯片/智驾，应用层仍有供应商空间。艾博连的定位就是「在华为底座上跑艾博连场景引擎」。

## 四、完整话术体系

### 4.1 30秒电梯演讲

> 东风已经搭建了鸿蒙座舱和天元智舱这样很好的技术底座——我们的角色不是再给一个底座，而是一个 Agent 工厂，让东风的产品经理能像搭积木一样快速生成千人千面的座舱场景，而且可以通过艾拉比已经通过的 OTA 通道直接推送上车。我们在奇瑞已经验证了这个模式。

### 4.2 3分钟技术交流版

> 东风现在的座舱技术架构在国内是第一梯队的——鸿蒙座舱、DeepSeek 全系接入、天元智舱四档分级。但我们在和长城、奇瑞合作中发现一个共性挑战：当底层 OS 和基础 AI 都就位之后，座舱体验的差异化反而更困难了，因为大家都在用同一套基础设施。
>
> 艾博连的 Agent 平台不是要替代鸿蒙或天元智舱——恰恰相反，我们运行在它们之上。我们解决的是三个具体问题：
>
> 第一，场景生成效率。一个座舱场景从产品经理提出到 OTA 上车，传统流程需要 4-6 个月。我们的低代码工厂可以把周期缩短到 4-6 周。
>
> 第二，停车体验。我们有一套叫做「忆停车」的方案，从入场自动标定到离场无感支付，完整闭环——这是我们最快能拿给你看的东西。
>
> 第三，不被大模型锁定。东风已经接入了 DeepSeek，但如果未来有更好的模型出现呢？我们的多模型网关可以让东风自由切换和组合。
>
> 我们和艾拉比是同一家母公司——这意味着我们对东风的 OTA 通道和服务流程已经很熟悉了。

### 4.3 15分钟深度方案版

结构：
1. 行业洞察 (3min) — 华为鸿蒙+DeepSeek 带来的同质化挑战
2. 艾博连定位 (2min) — 座舱神经系统 vs 骨架；奇瑞量产实践
3. 三个场景演示 (7min) — 忆停车 → 场景工厂 → 多模型融合
4. 合作模式 (2min) — 预研 → POC → 联合实验室 → 量产搭载
5. 时间窗口 (1min) — 奕派 Q3 车型仍有机会

### 4.4 针对华为合作的精准回应

| 对方可能说的话 | 回应 |
|--------------|------|
| 我们已经和华为深度绑定了 | 鸿蒙座舱解决的是骨骼和器官问题——OS、芯片、智驾感知。艾博连解决的是神经系统问题——让这些器官能协同思考。我们在奇瑞的华为座舱方案上已经验证了共存。 |
| 华为也有自己的座舱 Agent | 华为的 Agent 是全栈闭环的。我们的 Agent 平台让东风保留场景定义权，不被任何一家锁定。 |
| 华为有排他条款 | 可以先做预研合作——不涉及量产定点。另外，艾博连已经和华为 HMS For Car 在海外方案上联合预研。 |
| 天元智舱会覆盖这些功能 | 天元智舱做底层平台和基础能力，我们在上层做场景化体验，不是替代，是增强。 |

### 4.5 不同角色的区别化沟通

| 角色 | 关注点 | 话术策略 |
|------|--------|---------|
| 研发总院 | 技术可行性、兼容性 | 强调不改底层架构；OTA 通道已验证 |
| 品牌产品经理 | 用户体验差异化、上市速度 | 展示场景工厂 Demo，强调缩短上线周期 |
| 采购 | 供应商资质、价格 | 艾拉比已供应商身份；不做价格对比做 TCO |
| 海外业务团队 | GDPR/PDPA 合规、多语言 | 艾博连 + 华为 HMS For Car 海外方案已在预研 |

## 六、6个月行动分解

### 第一阶段：情报验证（W1-W2）

目标：回答三个关键问题——奕派座舱方案是否已锁定？东风对座舱 Agent 的紧急度？艾拉比渠道的配合意愿？

里程碑：
- W1 结束前：完成艾拉比内部沟通，拿到东风座舱供应商准入流程文档
- W2 结束前：完成关键问题评估，决定进攻路线

决策点：如果奕派已完全锁定 → 切换至备选路径

### 第二阶段：技术破冰（W3-W4）

目标：完成首次技术交流，留下具体可追踪的下一步

准备工作：
- 制作奕派/岚图专属 Demo（忆停车最低可行版本）
- 准备场景工厂原型界面（前端 Demo）
- 准备技术交流材料

里程碑：
- W3 结束前：联合艾拉比发出技术交流邀约
- W4 结束前：完成首次技术交流，拿到明确下一步

### 第三阶段：定点验证（W5-W8）

目标：拿到一个品牌的一款车型的试点/POC/预研合作

策略：
- 理想场景：奕派未锁定 → 量产 POC
- 中性场景：奕派已锁定 → 岚图预研合作
- 保守场景：奕派/岚图均不可行 → 与华为 HMS For Car 联合预研

里程碑：
- W6 结束前：完成 POC 或预研合作方案的首次提案
- W8 结束前：获得试点意向或合作协议 draft

### 第四阶段：标杆建设（W9-W16）

关键动作：
- 推动成立东风-艾博连联合创新实验室
- 完成 POC 技术验证
- 输出验证报告和量产路线图

里程碑：
- W12 结束前：联合实验室挂牌或 POC 验证完成
- W16 结束前：产出第一个可展示的东风车型 Demo

### 第五阶段：规模复制（W17-W24）

关键动作：
- 以验证成果向东风集团其他品牌推广
- 争取进入东风天元智舱生态伙伴目录
- 以东风合作为标杆推动独立融资

里程碑：
- W24 结束前：至少和第二个品牌进入技术交流阶段

## 七、30天速赢清单

### 第1周（即刻执行）

- 艾拉比内部沟通：约艾拉比负责东风客户的项目经理/销售，了解研发总院对座舱供应商的评估节奏、最近沟通内容、目标联系人
- 情报搜集：
  - 查看 etp.dfmc.com.cn 东风招投标平台，「智能座舱人力支持项目」中标结果
  - 脉脉上搜索东风研发总院座舱相关岗位人员变动动态
- 内部资源盘点：
  - 确认忆停车演示版状态
  - 确认场景工厂原型是否已有前端 Demo
  - 拉通艾拉比和艾博连的联合提案资源

### 第2周

- 完成攻防评估：写一份《奕派座舱方案锁定状态评估》1 页纸
- Demo 准备：忆停车演示设备确认 + 场景工厂 5 分钟交互式 Demo 线框图
- 行业内容预热：脉脉发一篇「智能座舱同质化困局」文章，建立专家形象

### 第3周

- 发出技术交流邀约：联合艾拉比，以「OTA+座舱AI 联合方案」名义发出正式邀约
- 准备交流材料：1 页定位说明 + Demo 清单 + Q&A 预判文档

### 第4周

- 执行首次技术交流（如约定达成）
- 拜访后 24 小时内发送定制化 OnePager + Demo 视频 + 下一步建议
- 复盘决策：确定是否加速进入 POC 阶段

### 30天判断标准

| 结果 | 判断 | 行动 |
|------|------|------|
| 拿到了技术交流或 POC 意向 | 积极 | 进入第二阶段 |
| 艾拉比配合但东风暂未回应 | 中性 | 寻找其他入口（盖世汽车「走进东风」） |
| 奕派已完全锁定无进入空间 | 消极 | 评估转向其他车企（奇瑞/长城已有基础） |
