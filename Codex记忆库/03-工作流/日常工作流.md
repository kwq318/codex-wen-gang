# 日常工作流

## 日流程

### 晨间（8:00 - 10:00）— 研究准备
- [ ] 扫一遍智能座舱、HMI、AI语音行业最新动态，标记对客户方案有影响的变化
- [ ] 查看主机厂动态（新车型发布、智能化配置、供应链变化），用 Obsidian 记录关键信息
- [ ] 规划当天拜访优先级和准备材料

### 主要工作时间（10:00 - 17:00）— 客户互动
- [ ] 客户拜访（现场或线上），按四组必问问题摸底
- [ ] 拜访后 24 小时内发跟进邮件，附定制化方案建议
- [ ] 回复客户技术和商务问题

### 收尾（17:00 - 18:00）— 记录归档
- [ ] 将当天客户沟通要点录入 Obsidian
- [ ] 更新客户需求与痛点库
- [ ] 规划明天的拜访任务
- [ ] 如果今天有重要决策或发现，记录到 [[Codex记忆库/04-决策记录/决策索引|决策记录]]

## 周流程

### 周一 — 规划
- [ ] 确定本周拜访优先级 TOP 3
- [ ] 准备本周脉脉/LinkedIn 内容选题（智能座舱/HMI/AI语音方向）
- [ ] 回顾上周客户跟进状态

### 周五 — 复盘
- [ ] 本周拜访总结（成交进展、卡点、竞品动态）
- [ ] 更新客户 pipeline 状态
- [ ] 发布本周行业内容

## 核心销售工作流

### 新线索开发
1. 行业展会/论坛/主机厂供应链活动 → 获取线索
2. Codex 研究目标公司（产品规划、座舱方案现状、决策链）
3. 准备个性化破冰话术（基于对方车型规划的痛点问题）
4. 首次接触 → 四组必问问题摸底
5. 24 小时内发定制化方案建议

### 客户拜访流程
1. **前三分钟**：用对方具体车型的座舱痛点破冰（不是推销产品）
2. **第 3-15 分钟**：四组必问问题（现状 → 痛点 → 时间节点 → 决策链）
3. **第 15-25 分钟**：方案匹配（只讲能解决的部分，不硬推全部）
4. **第 25-30 分钟**：约定下一步行动（Demo演示/出方案对比报告）
5. **拜访后**：24 小时内定制化跟进，记录到 Obsidian

### 内容创作流程
1. 从客户需求痛点库选题
2. 研究智能座舱行业趋势和竞品动态
3. 用 Codex 辅助撰写初稿
4. 人工打磨（确保准确、有实操价值）
5. 发布到脉脉/LinkedIn
6. 归档到 Obsidian
