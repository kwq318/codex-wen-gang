# 销售思维框架

## 默认分析框架

今后处理销售相关任务时，默认采用以下七维思维框架：

1. **第一性原理**：拆解客户表面需求，追问根本问题、当前基线、真实目标和不解决的代价。
2. **线性思维**：梳理问题—原因—影响—决策—行动的因果链，明确项目路径和下一步共同动作。
3. **系统思维**：同时观察业务、技术、质量、交付、财务、合规和长期复制，避免只优化单点。
4. **网络思维**：识别客户组织中的发起者、使用者、评审者、采购者、批准者、影响者和反对者。
5. **批判性思维**：区分事实、客户原话、证据、假设、判断和礼貌性反馈，不把“客户认可”直接当成商机进展。
6. **逆向思维**：预演失单、延期、低毛利、质量事故、回款和交付失败的原因，提前设置风险防线和退出条件。
7. **整合思维**：将客户问题、产品能力、技术方案、实施交付、商务条件、证据链和组织推动整合为可购买、可交付、可复制的方案。

## 销售推理顺序

```text
定义问题
→ 拆解本质
→ 梳理因果
→ 分析系统
→ 识别关系网络
→ 验证事实与证据
→ 反向预演失败
→ 整合方案与行动
```

## 执行要求

销售相关输出应尽量同时包含：

- 客户真正问题，而不是只复述客户表面要求；
- 已确认事实、待验证假设和证据来源；
- 客户业务、项目、技术、质量、财务和组织关系的影响；
- 关键决策人、支持者、反对者和采购路径；
- 失单、延期、交付、毛利和回款风险；
- 客户与我方的下一步共同动作、责任人和日期；
- 适用时，绑定 G0—G5 机会门、价值账、证据清单和复盘结果。

## 核心原则

> **第一性原理找本质，线性思维找因果，系统思维看整体，网络思维看关系，批判性思维验事实，逆向思维找风险，整合思维形成方案。**

这套框架是销售相关任务的默认分析方式；如具体任务另有明确要求，以用户当次要求为准。
