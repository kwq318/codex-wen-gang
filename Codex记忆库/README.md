# 🧠 Codex 跨项目永久记忆库

## 这是什么

这是 Codex 的跨项目永久记忆库。Codex 在每次任务开始前会自动读取本目录下的所有笔记，确保理解你的长期规划、偏好、工作流和历史决策。

## 目录结构

- [[01-长期规划/个人使命与愿景]] — 你是谁、你想成为什么
- [[01-长期规划/年度目标]] — 今年的核心目标
- [[02-偏好/工作偏好]] — 工作习惯、时间安排、沟通风格
- [[02-偏好/技术栈偏好]] — 技术选型、工具偏好
- [[02-偏好/沟通偏好]] — 沟通风格、语言习惯
- [[03-工作流/日常工作流]] — 重复性工作流程
- [[03-工作流/Codex协作规范]] — 与 Codex 协作的规则
- [[04-决策记录/决策模板]] — 决策记录模板
- [[05-项目记忆/项目索引]] — 各项目记忆入口

## 使用方式

1. **日常更新**：直接编辑对应笔记，下次 Codex 任务自动读取
2. **记录决策**：每次重要决策后，在 `04-决策记录/` 下创建新笔记
3. **项目归档**：在 `05-项目记忆/` 下为每个项目创建独立记忆

## 自动读取机制

- Codex 启动新任务时，先读取 `Codex记忆库/` 全部 `.md` 文件
- 通过 `.agents/memory/` 配置自动触发
- 每日笔记自动同步到本库
