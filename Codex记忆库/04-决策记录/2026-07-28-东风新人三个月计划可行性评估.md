# 东风新人三个月计划可行性评估与修改方向

**日期**：2026-07-28  
**状态**：已决定

## 背景

> 对《东风集团-新人入职三个月计划》进行可行性评估，判断其是否适合作为入职后的执行计划，并沉淀后续修改方向。

## 评估结论

> 计划方向可行，但当前版本更接近“30天客户首轮突破作战手册”，还不是完整的“三个月入职计划”。
>
> 建议保留“华为渠道 + 东风出口座舱”主线，但将90天目标明确为：完成客户需求确认、项目窗口验证、技术适配和POC/联合预研立项，而不是默认90天内拿到量产项目。

## 关键判断

| 维度 | 判断 |
|---|---|
| 东风作为重点客户 | 值得优先验证，但不能仅凭战略信号直接认定为主攻客户 |
| 华为联合切入 | 可行性较高，但取决于合作授权、实际集成深度和双方交付边界 |
| 全球化座舱方案 | 有基础，但仍需完成产品、接口、案例和合规证据确认 |
| 90天拿到POC/预研 | 有可能，应作为主要结果 |
| 90天拿到量产项目 | 概率较低，不应作为新人计划硬指标 |

## 决策

1. 将当前计划重新定义为“90天客户机会验证与POC推进计划”。
2. 保留“华为联合方案 + 东风出口座舱”作为主线，同时保留国内车型体验增强作为备线。
3. 在对外沟通前，先完成华为合作关系、联合交付边界、全球化Demo和合规能力的证据化确认。
4. 第一次客户沟通以项目发现为主，不预设东风已经确认GDPR、PDPA或跨市场座舱适配需求。
5. 用量化里程碑衡量进展：第7天完成内部验证，第30天完成需求和决策链确认，第60天形成POC任务书，第90天争取POC、联合预研或正式供应商评估机会。

## 必须修改的重点

### 1. 补齐后三个月内容

- 第1阶段（2026-08-03至2026-08-09）：内部验证、华为合作边界确认、账户建档。
- 第2阶段（2026-08-10至2026-08-30）：客户发现、项目筛选、决策链梳理。
- 第3阶段（2026-09-01至2026-09-30）：技术适配、合规预审、POC定义。
- 第4阶段（2026-10-01至2026-10-30）：商务立项、采购准入和下一阶段锁定。

### 2. 建立证据分级

- **已确认**：有合同、邮件、内部负责人或正式资料支持。
- **待确认**：已有口头信息，但还不能作为对外承诺。
- **销售假设**：基于公开信息或逻辑推断，需要客户访谈验证。

重点确认：华为关系是否可公开使用、是否允许联合拜访、HMS与艾博连的接口边界、联合报价和合同主体、全球化Demo是真集成还是能力展示、GDPR/PDPA及OTA合规能力的证据。

### 3. 修正合规和技术表述

- 不将GDPR简单表述为“车内数据脱敏后即可跨境传输”。
- 不将PDPA统一表述为“必须本地存储”。
- 不将UN R156等同于“有OTA通道即可满足合规”。
- 将“华为做底层、艾博连做上层”改为按目标车型和双方确认接口定义职责。
- 不使用“联合交付”“一次对接、底层+上层全部覆盖”等未经证据确认的强承诺。

### 4. 增加销售管理工具

- 《华为×艾博连合作边界确认表》
- 《出口座舱能力与证据矩阵》
- 《东风账户地图》
- 《目标车型/项目假设表》
- 《客户需求访谈纪要》
- 《目标项目资格评分表》
- 《POC任务书》
- 《三方职责边界表》
- 《采购流程图和机会卡》

## 90天里程碑

### 第7天

- 确认华为合作和对外话术边界。
- 确认华为侧对接人及东风引荐路径。
- 完成全球化Demo和产品成熟度评审。
- 确定至少一个目标项目或车型。

### 第30天

- 完成至少2次有效客户沟通。
- 找到业务和技术联系人。
- 识别目标市场、车型、项目阶段和SOP窗口。
- 识别至少3个真实客户痛点。
- 获得第二次技术交流或POC讨论机会。

### 第60天

- 形成目标项目需求说明、接口清单和数据合规风险清单。
- 明确华为、艾博连、东风三方职责。
- 完成POC范围、资源、周期和成功标准。
- 启动供应商准入和商务流程确认。

### 第90天

争取形成以下至少一项结果：

1. 付费POC；
2. 联合预研或技术合作协议；
3. 进入东风正式供应商/项目评估流程。

若未形成上述结果，必须记录明确原因、客户反馈、阻塞项和下一次触达日期，不以“持续跟进”作为结案结论。

## 对外定位原则

> 华为提供目标出口车型所需的海外车载生态和底层服务能力；艾博连在双方确认的接口范围内，负责跨品牌场景编排、HMI适配、Agent协同和运营管理。首次交流先确认车型、市场、现有架构和未解决问题，再判断是否适合开展小范围技术验证。
