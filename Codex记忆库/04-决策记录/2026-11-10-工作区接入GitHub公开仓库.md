# 📋 Codex文稿工作区接入 GitHub 公开仓库

**日期**：2026-11-10
**状态**：已决定

## 背景

> 将本地 Obsidian/Codex 工作区（`/Users/kangweiqing/Desktop/桌面文稿/codex文稿`）同步到 GitHub，实现笔记的云端备份与版本管理。

## 选项

| 选项 | 优点 | 缺点 | 风险 |
|------|------|------|------|
| A. 私有仓库 | 内容不公开 | 用户明确选择公开 | - |
| B. 公开仓库 + 全部上传 | 笔记公开可分享、全部内容上云 | 需处理 >100MB 文件限制 | 敏感信息可能泄露 |
| C. 排除大文件/依赖目录 | 推送可行、仓库干净 | 非字面意义的"全部" | - |

## 决策

- 仓库：`kwq318/codex-wen-gang`，**Public**，分支 `main`
- 认证：先用 fine-grained token 登录成功但无建仓权限 → 改用 classic token（勾选 `repo`）建仓成功
- 大文件处理：`.pw-browsers/`、`node_modules/`、`.venv/`、`__pycache__/`、`.DS_Store` 已通过 `.gitignore` 排除（本地保留，不上传）；83MB `embeddings.json`、51MB dmg 等 >50MB 文件仅警告，已正常上传
- 推送方式：HTTPS 因 github.com 连接不稳定多次失败（HTTP2 framing / Empty reply / 408），最终改用 **SSH** 推送成功
- SSH 配置：新生成 `~/.ssh/id_ed25519`（注释 `kwq318-devin`），公钥通过 `gh api user/keys` 添加，标题 `devin-cli-mac`；remote 已改为 `git@github.com:kwq318/codex-wen-gang.git`

## 影响范围
