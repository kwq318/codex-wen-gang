# 安装 ECC (Everything Claude Code) 并配置销售技能

**日期**：2026-07-21
**状态**：已决定

## 背景

> 业务需要 AI 辅助销售全流程：客户线索挖掘、竞品分析、方案撰写、外联邮件、行业内容输出。每次手动操作效率低，需要一个标准化的技能框架来统一管理能力。ECC 是 GitHub 210K+ star 的开源 Agent 能力框架，支持 Codex/Claude Code/Cursor 等多平台，内置 261 个技能、64 个 Agent，可筛选安装。

## 选项

| 选项 | 优点     | 缺点     | 风险     |
|------|----------|----------|----------|
| A. 安装 ECC | 一次安装覆盖销售全链路技能，持续更新，社区活跃 | 技能数量多，需筛选使用；需 npm 网络依赖 | 技能质量参差，部分为开发向，需人工筛选 |
| B. 手动维护技能 | 完全可控，无外部依赖 | 维护成本高，更新靠手工 | 容易过时，覆盖面窄 |

## 决策

> 选择 **ECC + 销售导向配置**。通过 `ecc` CLI 以 `research` 配置为基础，叠加 `content`/`social`/`operators` 能力集，安装至 `~/.codex/` 和 `~/.claude/` 双目标。共安装 222 个技能 + 60+ Agent。

## 影响范围

- **新增工具**：`ecc` CLI（npm 全局包 `ecc-universal`）
- **Codex 配置**：`~/.codex/AGENTS.md`（ECC Codex 补充指导）、`~/.codex/config.toml`（平台配置）
- **Claude Code 备用**：`~/.claude/ecc/`（59 个技能）
- **工作区不冲突**：`AGENTS.md` 中销售角色定义和记忆库规则完整保留
